# Roadmap

本页只维护 rebuild 仓库尚未完成的成果。Duolingo 试验已结束，案例状态与历史由[案例状态](../projects/duolingo-web/STATUS.md)和[历史索引](history/README.md)维护，不在此续写课程批次或运行 Goal 状态。

| 优先级 | 待完成成果 | 验收依据 |
| --- | --- | --- |
| 1 | 用统一 workflow 完成含提交与持久化的完整业务旅程 | 全旅程、严格前端与持久化仍需实际验证。用户重新授权的案例需完成需求级验收 |
| 1 | 把用户需求与细粒度测量建立稳定映射 | 报告先显示主页／交互／声音等需求缺口，再展开对应场景和诊断；断言数量不作为完成率 |
| 2 | 从实际案例提取已验证的原生恢复、加载就绪与AX字段采集能力 | 用同名背景控件、数字字段名称、刷新无HTML节点等真实反例验证；减少固定协议复制，不先批量重写 |
| 2 | 补齐原生与音频的共同准备判定、浏览器相对几何原点及动态媒体可比性 | 浏览器已接入[逐步采集与准备门禁](BROWSER-CAPTURE.md)；原生、音频和跨时刻媒体仍需真实事实及明确不可比原因，保留原始测量 |
| 2 | 验证RSI策略对真实未访问分支与漏采的选择效果 | 历史树／全池回放／实际再部署的固定探针分数不能证明更广需求发现。保留原始结果，不恢复已结束案例，不先做消融 |
| 3 | 按实际宿主需求收敛手动 MCP 验证工具／Pipeline | Stop Hook 已删除；剩余工具仅按已确认的手动验证或固定批次需求收敛 |

当前入口和职责见 [README](../README.md)、[Workflow](../workflows/rebuild/WORKFLOW.md)及 [架构](ARCHITECTURE.md)。原论文和既有实验继续保留于 [研究说明](RESEARCH.md)，新的研究实验不是上述工程工作的前置条件。
