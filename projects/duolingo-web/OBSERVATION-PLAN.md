# Duolingo 网页观察计划

本文件保留首次接入计划和历史清单，不能作为当前覆盖或完成证明。当前完整目标由运行 Goal 管理，阶段进展见 [ROADMAP](../../docs/ROADMAP.md)，逐项验收见版本化前端契约。2026-10-11审计已撤回原创素材与缩小目标的旧限制。

## 范围与入口

参考入口为 https://www.duolingo.com/ 。先检查实际页面、登录状态、界面语言和可访问课程，优先使用可恢复的访客学习路径。平台版本以可见版本或观察日期记录，未显示则 unknown。现有证据来自实际访客学习路径，账号及付费状态未覆盖，继续作为探索缺口记录。

历史首批接入从一个短课开始（不是完整复刻范围）：进入课程、选择题或拼句、提交前的空答案边界、正确/错误反馈、下一题、退出及返回。题型和规则必须实际出现后才能转成验收，不假定每条路径都可访问。第二批专门寻找首批遗漏，优先检查错题重练、退出是否保存、刷新恢复及结算到学习路径的状态关联。

## 从证据到冻结批次

观察证据 → 行为项及前置状态 → 单一场景动作与预期 → 原版适配实际执行 → 原版回执 → 冻结批次 → Swift 原生动作适配。以上各步有实际产物后才推进；不能以本清单充当规格或给 unknown 补上断言。

线上原版通常没有任意夹具注入和完整重置接口。只有实际可操作的访客重开、课程重练或可恢复前置状态才能用于原版验收。若无法回到同一状态，报告 unavailable，保留未覆盖项继续探索；可把已观察规则另建为明确标记的 local_reference，但不缩减整个目标；本地参考不等于线上原版，也不覆盖未观察的服务器规则。原版与本地参考的结果分开报告。

数据夹具可以编译实际观察到的原版实例并控制候选应用存储，不能声称它已注入 Duolingo。跨端比较使用同一题面、业务场景与前端断言；不能把两份独立标准称作同一 E2E。Swift 核心测试、原生 UI 验收、视觉审查分别记录。

## 当前页面与初始题单

初始sessions响应不等于暂缓或自适应后的实际题单。每次变题以当前可见DOM及其渲染的公开challenge字段、实际动作/反馈和PNG确认，不从旧题单猜角色或语音。公开题目数据可能带评分答案，采集它不算盲探索收益；不得读取或保存challengeState、用户、会话和追踪对象。当前题单/素材身份、像素及声学输出分别验证。字段不可读时保留unknown，不回退成旧实例。
